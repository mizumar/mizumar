## Main Projects

### スマートクレカ比較

- リポジトリ: https://github.com/mizumar/smart-card-select
- 公開サイト: https://smart-card-select.vercel.app/

クレジットカードを条件や目的から比較し、自分に合った1枚を探せるWebアプリケーションです。
2つの質問に答える診断、タグでの絞り込み、2枚比較、お気に入り、検索、コラム記事などを実装しています。
公開して運営中であり、SEOや内部リンクなどの改善を継続しています。

- 技術: Next.js / React / TypeScript / Tailwind CSS / Zustand
- テスト・開発の流れ: Jest / Vitest / Playwright / GitHub Actions、GitHubのIssueとPull Requestを使って開発

### ホテル検索アプリ

- リポジトリ: https://github.com/mizumar/hotel-comparison-app
- 公開サイト: https://hotel-comparison-app.vercel.app/

楽天トラベルAPIを利用し、キーワードや条件からホテルを検索できるWebアプリケーションです。
検索条件のURL保持、お気に入り（Zustand）、ホテル詳細表示を実装しています。
外部APIのレスポンスをアプリ用の型に変換する処理や、TanStack Queryによるデータ取得の管理に取り組みました。

- 技術: Next.js / React / TypeScript / TanStack Query / Zustand
- テスト: Jest
